文件夹更新
关闭 SIMUWELD SD 程序，将包内 shared 与 modules 两个文件夹复制到 SIMUWELD-SD-Web.exe 所在目录，覆盖同名文件，然后重新启动。

局部模型
1. 上传原始瞬态 DAT，并选择正确的模型单位。
2. 在“局部试算 / 局部模型”中选择焊路范围、模型裁剪范围，保存试算分组。
3. 填写来源和目标 Process 名称；组件名称与 Simufact 项目显示名称不同时，在组件对应中填写准确名称。
4. 导出 ZIP 并完整解压。在已打开来源项目的 Simufact 中运行 create_local_case.py。
5. 脚本创建独立 Process，替换局部网格、建立局部焊路与热源副本，并保持各次经过的真实时间间隔。Base 保持完整。
6. 在 Simufact 中检查切割面的热边界、局部连接与夹具接触，生成 DAT 并计算。最长冷却时间内，全部试件最高温度不超过设定值时停止；默认停止温度 26℃、最长冷却 60 s。

结果处理
1. 填写局部 Process 名称，导出结果提取脚本，在对应 Simufact 项目中运行。
2. 提取初始、每次焊接冷却后的必要状态。中间状态使用下一次焊接开始前的最后一个保存结果，保持原工艺间隔。
3. 最终时刻可以填写，适用于已有结果中需要排除解除夹具阶段的情况。
4. 导入结果 ZIP。旧版结果 ZIP 还需选择局部求解 DAT；新版自带事件时间。
5. 默认代表长度为 1 mm，取局部焊路中间。修改代表长度或横向统计区间数量后自动重新计算。
6. 每块板分别提取塑性应变的厚度零阶、一阶矩，得到面内收缩与曲率。后续焊接使用累计代表量之差。
7. 页面显示实际状态时刻、板厚和最高温度。未满足冷却条件的结果会明确提示，并随计算包记录。

Abaqus
1. 导入整体 shell INP 并指定单位。目标网格独立生成，与 Simufact 节点编号没有对应要求。
2. 为目标实体选择代表板件。支持 S3、S4R、S4 和统一厚度、计算期间积分的均质 shell 截面。
3. 焊路使用已导入 DAT 中的坐标。勾选参与路径，拖动调整顺序，使用反向按钮改变方向。
4. 按代表长度自动分段；目标单元跨越多个分段时，根据实际面积交集分配增量。相邻分段不重复覆盖，不同焊接遍次分别累计。
5. 导出并完整解压计算包。在 Abaqus 6.14-5 命令环境运行：
   abaqus cae noGUI=prepare_abaqus_model.py
6. 官方接口读取原始 INP，生成计算名称对应的文件夹，其中包括 INP、CAE、Fortran、加载数据和映射报告。
7. 在该文件夹执行：
   abaqus job=计算名称 user=local_shell_loading.for datacheck interactive
   datacheck 成功后再提交计算。需要可用于 Abaqus 6.14-5 的 Fortran 编译环境。

装配 INP
含 Part / Instance 的模型，在页面导出装配预览脚本，将其放在 INP 所在目录并运行：
abaqus cae noGUI=export_abaqus_preview.py
随后在 SD 同时选择原始 INP 和生成的 JSON。预览与原文件摘要需要一致。

测试示例
SD_TwoPlates_Test.inp：使用真实局部结果的坐标范围和厚度，生成 2748 节点、2598 个 S4R 单元的规则两板模型。
测试材料为 E=70000 MPa、nu=0.33；两块板分别固定最小 X 边界。未定义板间连接。
SD_TwoPlates_Abaqus.zip：基于当前真实两次焊接结果生成的完整计算包，可直接检查官方接口准备步骤。
示例中的材料与约束仅服务流程检查。工程材料、连接和约束由用户的 INP 定义。

检查范围与使用范围
已完成真实 DAT 裁剪与接口、真实 UNV 积分点数据核对、截面矩保持、逐次增量、共享分段边界、测试 INP 导入与打包、浏览器操作及文件夹覆盖加载检查。
当前目录的实际 EXE 已完成离线模块加载、真实数据读取和测试 INP 计算包导出检查。
当前真实末态最高约 32.29℃，未达到默认 26℃条件；其数据用于流程检查，工程精度需要冷却完整的结果验证。
当前面积映射适用于与代表板件方向一致的平面薄板、简单平面焊路和均质 shell。自交路径或超过代表数据的重复焊接次数会明确停止导出。
横向分布保留多个统计区间；跨越多个区间的目标单元采用面积平均，局部峰值会受到目标网格分辨能力影响。
没有执行 Simufact 内部脚本、Abaqus 6.14-5 编译、datacheck 或实际求解；整体翘曲与鼓包的预测精度尚未验证。
