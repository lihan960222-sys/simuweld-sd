# SIMUWELD SD

用于本机 sfMarc 模型操作的工作区。共用模型、三维视窗与显示设置，通过顶部入口切换功能。提供模型浏览、面载荷定义与生成焊路，分别导出增加载荷后的 DAT 文件组或 Simufact Python 脚本。

模型文件仅在本机处理，原文件保留。浏览器与 Python 服务通过 `127.0.0.1` 通信，页面资源随程序提供。

0.5.0：支持网格与 STEP 几何背景、完整激光热源参数、按比例圆锥示意图、焊枪与移动光源预览，以及独立 Python 脚本导出。网页与 Windows 程序采用激光焊接图标。导入文件或修改输入后，刷新、关闭或离开页面时要求确认，选择取消会保留当前页面中的输入。

视图按钮采用坐标轴图标，“回到中心”保留当前旋转角度与缩放；视窗显示随视角变化的 XYZ 指示。网格边线使用原始单元外表面的边界。导出提示在下次点击时渐隐。

顶部提供“模型”“面载荷”和“生成焊路”入口，切换时保留各功能的编辑内容与实体显示设置。实体支持透明度百分比拖条。默认单位制为 mm、t、N、MPa。

## Windows 使用

1. 解压整个程序目录，双击 `SIMUWELD-SD.exe`。保留同目录的 `_internal` 文件夹。
2. 浏览器会自动打开。选择 `.dat`；文件引用 INCLUDE 时选择包含相关文件的模型目录，并指定主 DAT。
3. 在“模型”中浏览网格；左侧可以设置单位、分别显示实体、修改颜色。勾选“半透明”后拖动透明度，0% 为不透明，100% 为全透明；取消勾选恢复不透明，重新勾选保留拖条数值。
4. 点击顶部“面载荷”，点击模型表面并调整相邻面最大夹角。选择方式支持替换、增加、移除。
5. 输入载荷大小和单位，选择沿法向向内、向外，或者输入全局坐标中的方向分量。手动方向会自动归一化。
6. 选择载荷生效阶段，预览箭头、面积与合力，保存载荷。
7. 可以继续添加载荷，也可以编辑或删除已有载荷。重叠区域在相同阶段按载荷求和。切换到“模型”浏览后，返回“面载荷”可以继续编辑。
8. 导出 ZIP，解压后使用名称带 `_loaded.dat` 的主文件。ZIP 同时包含导入的关联文件及 `sfmarc-loads-report.json`。

程序窗口关闭后，本机服务停止。浏览器页面关闭不会自动终止服务。

载荷、选面与编辑内容保存在当前页面中。导入文件或修改参数后，刷新、关闭或离开页面会出现浏览器确认。导出后仍保留确认，以保护页面中的编辑状态。确认文字由浏览器提供；强制终止浏览器或电脑断电时无法显示确认。

左键拖动旋转，右键拖动平移，滚轮缩放。旋转支持连续翻转。实体显示开关保持当前旋转、缩放与画面位置；点击“回到中心”后，以当前可见实体为中心并保留旋转角度与缩放。三个坐标轴图标分别切换到 XY、XZ、YZ 平面，图标中的水平方向和竖直方向对应切换后的视图。右上方的 XYZ 指示随视角转动，X、Y、Z 分别使用红色、绿色、蓝色。

勾选“网格边线”后，显示原始单元外表面的边界；六面体的四边形表面保持四边形网格。导出完成后，再次点击页面，提示框会在约 0.3 秒内消失。

## 输入与载荷定义

- 网格读取：meshioplusplus 17.11.0。使用其原始连接关系接口，保留节点、单元编号和退化单元的面号。
- 已实现的实体单元类型：7、134、136。type 7 的重复节点退化单元包含在处理范围内。
- 通过共享节点关系识别连续实体，坐标重合的不同节点不合并。只有外表面可以被选择。
- 沿法向的压力：TABLE 形式 `DIST LOADS`，normal pressure，正值向内、负值向外。
- 手动方向：general traction，分量为输入大小乘以单位方向向量，计量为力除以面积。
- 根据 Marc Volume C 的 FACE IDS 表确定局部面号，按局部面号组织原始单元列表。
- 在选定 LOADCASE 中增加新载荷标签，阶段内恒定；默认选择全部历史计算阶段。
- 法向随动行为保持原文件的 `FOLLOW FOR` 设置。预览表示初始几何上的方向与合力。
- 包含 `FOLLOW FOR` 时，手动方向面力的组合尚未验证，当前停止该组合的导出。
- 原始数据按字节保留，仅新增载荷定义及修改指定 LOADCASE 的数量和标签。修改记录能够恢复原文，用于核对。
- 中文阶段名称支持 UTF-8 与 GB18030/GBK，导出保留原始编码。
- 长度与力单位作用于整个模型；修改后，全部已保存载荷会重新换算，完成后可以直接导出。
- 默认单位制：长度 mm、质量 t（吨）、力 N、压力 MPa；时间采用 s 时，该组合保持量纲一致。1 MPa = 1 N/mm²。面载荷计算使用长度、力与压力单位；原文件的坐标、密度和材料数值保持原值。
- INCLUDE 限于用户选定的文件组，不允许目录越界、循环引用、超过 10 层或同一文件重复引用。
- 单次导入文件组上限 512 MB、512 个文件。程序不读取未由用户选择的外部文件。

## 生成焊路

1. 可在左侧打开 Marc DAT，或通过“导入几何背景”打开 Abaqus INP、Nastran BDF/NAS、CAD STP/STEP。Nastran 使用 DAT 扩展名时，在背景格式中选择 Nastran。实体分别支持颜色、透明度和显示开关。STEP 通过 OpenCASCADE 转为显示网格，坐标单位为 mm；INP/BDF 使用左侧指定的模型长度单位。几何背景按连通表面识别实体；高阶网格按角点显示，CAD 显示三角化表面。当前背景入口读取独立文件，包含 INCLUDE 的 INP/BDF 需要由原软件输出完整网格。面载荷功能使用 Marc DAT。
2. 点击“生成焊路”，在顶部编辑功率 W、速度 mm/s、效率 0–1，以及圆锥上部半径、下部半径、深度、Gaussian 参数、体积热量比例、表面圆盘半径、表面搜索深度、表面 Gaussian 参数。尺寸单位为 mm，示意图使用统一尺寸比例；初始数值可以编辑。全部焊路使用这组参数。选择 CSV 坐标单位，导入一份或多份 CSV。
3. 选择当前路径，默认使用整条路径。选择起点和终点时，程序保留中间全部原始点；也可以按“拾取起点”“拾取终点”后点击视窗中的 CSV 原有点。起点绿色、终点红色。点击“反向”交换起终点，“定位路径”查看当前范围。
4. 输入焊路名称与焊后停止时间（秒），点击“添加到顺序列表”。同一条 CSV 路径可以多次添加，分别指定范围、方向、名称和停止时间。列表从上到下执行，支持编辑、上移、下移和删除。
5. 填写已有 Process、空 Robot 或新 Robot 名称，以及新热源名称。设置 local-vector 方向向量（自动归一化，默认 0、0、1）。预览将焊枪放在该方向一侧，圆锥沿反方向进入模型；导出保持相同方向向量。
6. 使用“播放”“暂停”“回到起点”和进度拖条检查顺序。焊接时间等于路径长度除以速度，焊后停留时关闭光源；停留结束后进入下一条焊路起点。播放倍速只影响网页预览。移动光源和圆锥用于检查位置、方向与时间，温度场需在 Simufact 中计算。
7. 点击“导出 Python 脚本”，得到 `generate_weld_paths.py`，坐标、热源参数和停止时间均已包含。在 Simufact Welding 中打开目标 Project，通过其 Python 脚本入口执行文件。脚本创建新的 HeatSourceWeldingParameter 和 HeatSourceLaser，按顺序创建 WeldLine 与 Robot Trajectory，并设置 `Trajectory.index`。同名热源、同名 WeldLine 或已有 Trajectory 的 Robot 会终止执行。

CSV 使用 UTF-8（支持 BOM）和逗号分隔，列名区分大小写。必需列是 `X,Y,Z` 和点序列 `Order`，点序也支持 `Index`、`PointOrder` 或 `PointID`。可选 `PathID` 或 `WeldID` 区分同一文件中的多条路径，可选 `NodeID` 显示原始编号。没有路径编号时每个文件是一条路径。每条路径按点序升序读取，不同文件单独分组。CSV 的其他列不设置网页热源参数、方向或停止时间，这些值以网页输入为准。

```csv
PathID,Order,NodeID,X,Y,Z
Path-A,1,1001,0,0,0
Path-A,2,1002,10,0,0
Path-A,3,1003,20,5,0
Path-B,1,2001,40,0,0
Path-B,2,2002,50,0,0
```

CSV 单位在导入时换算为 mm 保存；模型长度单位用于三维显示换算。两份数据需使用同一坐标系。程序保留全部路径点，连接顺序由点序列确定。每条路径至少包含两个点；点序重复、相邻点重合、非有限坐标和缺少必要列会停止导入并显示原因。一次导入总大小限制 20 MB，当前页面最多导入 1000 条路径、10 万个点；焊接列表最多 1000 条、累计 100 万个点。

INP/BDF 几何背景使用全局坐标下的独立网格。包含 PART、INSTANCE、SYSTEM 的 INP，以及 GRID 使用局部坐标的 BDF，会明确提示转换要求；请由原建模软件输出全局坐标网格后导入。

焊后停止时间对应 `PauseEnd`，`PauseStart`、`LeadTime` 和 `FollowUpTime` 为零。热源使用 `specification.mode="transient-direct"`，设置功率、效率与速度；创建后读取并核对全部参数。脚本同时核对路径点数、长度、热源分配与执行顺序。API 执行中发生异常时会立即终止，Project 中可能保留已经创建的对象。生成完成后使用 Simufact 自身的保存功能保存 Project。

本机没有 Simufact Welding，尚未验证软件内实际创建对象与 PauseEnd 执行效果。

## 从源码运行

需要 Python 3.12 或更新版本、Node.js 22.12 或更新版本。开发环境首次安装需要网络；程序运行不访问外部服务。

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-lock.txt
.venv/Scripts/python.exe -m pip install -e ".[dev]"
npm ci
npm run build
.venv/Scripts/python.exe -m sfmarc_workbench.launcher
```

```powershell
$env:SFMARC_TEST_DAT = "D:/models/model.dat"
$env:SFMARC_TEST_WELD_CSV = "D:/models/nodes.csv"
.venv/Scripts/python.exe -m pytest
```

项目的实际用户模型专项测试仅在对应模型输入下执行。公共测试样本通过固定 commit 下载到被忽略的 `work/`，文件摘要会被核对。

```powershell
.venv/Scripts/python.exe scripts/fetch_sample.py
$env:SFMARC_TEST_DAT = "$PWD/work/elemtype7_tension.dat"
.venv/Scripts/python.exe -m pytest
```

Windows 打包：

```powershell
./scripts/build.ps1 -Python .venv/Scripts/python.exe
```

三维显示检查使用实际模型和本机 Edge，验证惯性衰减、连续翻转、旋转中心、箭头比例、实体颜色与透明度，以及坐标平面、斜视和放大视图的渲染数值：

```powershell
$env:SFMARC_TEST_DAT = "D:/models/C0002-3.dat"

npm run test:viewer
```

## 维护与扩展

- `deck.py`：输入文件与 INCLUDE、LOADCASE 位置、原始数据。
- `geometry.py`：表面提取、Marc 面号、法向、积分与角度选择。
- `background.py`：INP/BDF/STEP 第三方读取、表面显示与实体识别。
- `loads.py`：载荷数据、单位换算、合力与导出。
- `welding.py`、`weld_script.py`：CSV 读取、焊路输入检查与 Simufact 脚本生成。
- `server.py`：本机 API、请求来源与会话校验。
- `frontend/viewer.ts`：三维显示、点击与高亮。
- `frontend/main.ts`：共用模型操作、功能入口、参数面板与载荷操作。
- `frontend/welding.ts`：路径选择、焊接顺序、停止时间与脚本导出。
- `frontend/heatSettings.ts`、`weldTimeline.ts`：热源表单、尺寸示意图与按物理时间播放。

功能入口由 `workspaceTools` 定义，`activateTool` 统一切换按钮状态、参数面板和三维标记。功能参数区使用 `data-tool` 与入口 ID 关联；`activate` 恢复该功能的三维标记，`pick` 处理点击表面。模型导入、单位、实体显示和相机控制共用，功能切换保留表单与编辑状态。增加功能时在此列表登记入口并提供对应面板与交互处理。

新增二开功能应复用原始编号和表面数据。新增单元类型需要先核对 Marc 官方连接关系和面号，再使用真实输入验证。源码库不包含用户模型与计算结果。
