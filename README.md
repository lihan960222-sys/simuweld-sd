# SIMUWELD SD

0.8.0 Hallmark 界面版本：深色顶部模块栏、浅色三维视窗、实体列表与参数面板。颜色、字体、间距集中定义在 `frontend/tokens.css`，本版本保存在独立目录中。

用于本机 sfMarc 模型操作的工作区。共用模型、三维视窗与显示设置，通过顶部入口切换功能。提供模型浏览、面载荷定义与生成焊路，分别导出增加载荷后的 DAT 文件组或 Simufact Python 脚本。

模型文件仅在本机处理，原文件保留。浏览器与 Python 服务通过 `127.0.0.1` 通信，页面资源随程序提供。

0.7.0：焊接预览沿移动路径保留红色轨迹，进度拖条同步控制着色范围。编辑时未选路径点显示灰色，选中点显示黄色；预览时隐藏路径选点。热源示意图以蓝色填充显示表面圆盘，并保持尺寸比例。CSV 每次导入一份，重复导入相同内容保留已有列表；更换 CSV 时确认清空焊路，已创建热源保留。

视图按钮采用坐标轴图标，“回到中心”保留当前旋转角度与缩放；视窗显示随视角变化的 XYZ 指示。网格边线使用原始单元外表面的边界。导出提示在下次点击时渐隐。

顶部提供“模型查看”“面载荷”和“生成焊路”入口，切换时保留各功能的编辑内容与实体显示设置。模型导入时选择文件单位制，页面长度、面积与合力分别以 mm、mm²、N 显示，默认压力输入为 MPa。

## Windows 使用

1. 解压整个程序目录，双击 `SIMUWELD-SD.exe`。保留同目录的 `_internal` 文件夹。
2. 浏览器会自动打开。点击左上角上传图标，选择文件单位制，再选择 DAT、INP、BDF、NAS、STP 或 STEP 文件。Marc 引用 INCLUDE 时可以一起选择关联文件，或选择模型目录并指定主 DAT。Nastran DAT 在输入格式中指定。导入后再次点击上传图标，会清除当前模型与面载荷，再打开导入窗口；CSV 和热源设置保留。
3. 在“模型查看”中浏览网格；实体树按体积从大到小排列，根节点复选框控制全部实体。展开实体后，勾选“半透明”并拖动透明度，0% 为不透明，100% 为全透明。模型信息通过信息图标显示，支持鼠标停留或点击。参数分组通过标题展开、折叠；操作图标提供悬停提示。
4. 点击顶部“面载荷”，点击模型表面并调整相邻面最大夹角。选择方式支持替换、增加、移除。
5. 输入载荷大小和单位，选择沿法向向内、向外，或者输入全局坐标中的方向分量。手动方向会自动归一化。
6. 选择载荷生效阶段，选面与参数提交时自动显示箭头、面积和合力，点击保存图标保存载荷。
7. 点击载荷名称显示该项；勾选列表中的多个载荷可以同时显示，分组标题旁的图标控制全部载荷显示。编辑、删除通过对应图标操作。重叠区域在相同阶段按载荷求和。切换到“模型查看”浏览后，返回“面载荷”可以继续编辑。
8. 导出 ZIP，解压后使用名称带 `_loaded.dat` 的主文件。ZIP 同时包含导入的关联文件及 `sfmarc-loads-report.json`。

程序窗口关闭后，本机服务停止。浏览器页面关闭不会自动终止服务。

载荷、选面与编辑内容保存在当前页面中。导入文件或修改参数后，刷新、关闭或离开页面会出现浏览器确认。导出后仍保留确认，以保护页面中的编辑状态。确认文字由浏览器提供；强制终止浏览器或电脑断电时无法显示确认。

左键拖动旋转，右键拖动平移，滚轮缩放。达到模型外侧的近距离后，继续滚动可继续放大，速度约为普通缩放的五分之一。旋转支持连续翻转。实体显示开关保持当前旋转、缩放与画面位置；点击“回到中心”后，以当前可见模型为中心并保留旋转角度与缩放。三个坐标轴图标切换到 XY、XZ、YZ 平面，并以可见模型取景；没有可见模型时以路径取景。右上方的 XYZ 指示随视角转动，X、Y、Z 分别使用红色、绿色、蓝色。

视窗支持透视与正交投影，以及实体、框线、实体与边线三种渲染方式。边线采用原始单元外表面边界，六面体保持四边形网格。爆炸图拖条控制实体展开程度，仅改变显示位置；进入生成焊路时恢复模型位置。左右侧栏边界可以拖动，视窗随宽度变化调整并保持当前视角。导出完成后，再次点击页面，提示框会在约 0.3 秒内消失。

## 输入与载荷定义

- 网格读取：meshioplusplus 17.11.0。使用其原始连接关系接口，保留节点、单元编号和退化单元的面号。
- 已实现的实体单元类型：7、134、136。type 7 的重复节点退化单元包含在处理范围内。
- 通过共享节点关系识别连续实体，坐标重合的不同节点不合并。只有外表面可以被选择。
- 沿法向的压力：TABLE 形式 `DIST LOADS`，normal pressure，正值向内、负值向外。
- 手动方向：general traction，分量为输入大小乘以单位方向向量，计量为力除以面积。
- 根据 Marc Volume C 的 FACE IDS 表确定局部面号，按局部面号组织原始单元列表。
- 在选定 LOADCASE 中增加新载荷标签，阶段内恒定；默认选择全部历史计算阶段。
- 法向随动行为保持原文件的 `FOLLOW FOR` 设置。预览表示初始几何上的方向与合力。
- 包含 `FOLLOW FOR` 时，手动方向面力的组合尚未验证，当前停止该组合的导出。
- 原始数据按字节保留，仅新增载荷定义及修改指定 LOADCASE 的数量和标签。修改记录能够恢复原文，用于核对。
- 中文阶段名称支持 UTF-8 与 GB18030/GBK，导出保留原始编码。
- 文件单位制在导入窗口中选择 m、kg、s、N、Pa 或 mm、t、s、N、MPa。界面采用毫米、牛顿显示；导出的载荷换算至文件单位，原始坐标、密度和材料数值保持原值。
- 实体体积由封闭表面计算。无法可靠计算的体积显示“体积未确定”并排在列表末尾；STEP 体积精度受显示网格精度影响。树形结构为模型文件、连通实体及显示属性。
- INCLUDE 限于用户选定的文件组，不允许目录越界、循环引用、超过 10 层或同一文件重复引用。
- 单次导入文件组上限 512 MB、512 个文件。程序不读取未由用户选择的外部文件。

## 生成焊路

1. 通过左侧“打开模型”导入 Marc DAT、Abaqus INP、Nastran BDF/NAS 或 CAD STP/STEP。实体分别支持颜色、透明度和显示开关。STEP 通过 OpenCASCADE 转为显示网格，依据文件长度定义转换为 mm；INP/BDF 使用导入窗口指定的模型长度单位。几何背景按连通表面识别实体；高阶网格按角点显示，CAD 显示三角化表面。INP/BDF 使用独立完整网格，面载荷功能使用 Marc DAT。
2. 点击“生成焊路”，填写热源名称、功率 W、速度 mm/s、效率 0–1，以及圆锥上部半径、下部半径、深度、Gaussian 参数、体积热量比例、表面圆盘半径、表面搜索深度、表面 Gaussian 参数，然后点击“创建热源”。尺寸单位为 mm，示意图使用统一尺寸比例。点击“新增热源”可以创建其他参数组；选择已有热源可修改并保存，改名会同步更新焊路引用。
3. 在左侧“路径点”中选择 CSV 坐标单位，导入一份 CSV；使用文件旁的复选框控制路径显示。已有模型时保持当前旋转、缩放、画面位置及旋转中心，路径按原始坐标和单位换算叠加；仅导入 CSV 时自动显示全部路径。切换到其他模块后返回会恢复 CSV、显示状态、路径范围与编辑内容。默认使用整条路径；文件内有多组路径时，点击对应组的点即可选择。指定起终点时保留中间全部原始点。鼠标悬停在原有点上时点亮，点击可指定起点或终点。未选点显示灰色，选中点显示黄色，点击“反向”交换起终点。重复导入相同内容保持已有焊路；更换 CSV 时确认清空焊路列表，热源参数保留。
4. 在“焊路”分组中输入名称、选择热源、填写焊后停止时间（秒），点击添加图标。保存后恢复拾取起点，下一次点击路径点会设置新起点。列表从上到下执行，通过拖动柄调整顺序；拖动柄获得焦点后也可使用上下方向键。编辑、删除使用图标，每条焊路可以重新分配热源。
5. 填写已有 Process、空 Robot 或新 Robot 名称。设置 local-vector 方向向量（自动归一化，默认 0、0、1）。预览将焊枪放在该方向一侧，圆锥沿反方向进入模型；导出保持相同方向向量。
6. 点击已保存焊路的名称循环播放该条焊路，包含焊后停止时间；使用全部播放图标按列表顺序播放。播放、暂停、复位、速度拖条和进度拖条位于同一分组，速度范围为 0.1× 至 20×；速度拖条的左半段对应 0.1× 至 1×。预览期间隐藏路径选点及选中连线，保留红色已焊轨迹；返回编辑时恢复选点。每条焊路使用对应热源的速度和尺寸，着色带宽度取圆锥上部半径与圆盘半径中的较大值。拖动进度同步改变着色范围，复位清除着色；焊后停留时关闭光源。移动光源、圆锥和着色用于检查位置、方向与时间，温度场需在 Simufact 中计算。
7. 点击“导出 Python 脚本”，得到 `generate_weld_paths.py`，坐标、全部热源参数、逐条分配关系和停止时间均已包含。在 Simufact Welding 中打开目标 Project，通过其 Python 脚本入口执行文件。脚本创建各组 HeatSourceWeldingParameter 和 HeatSourceLaser，按顺序创建 WeldLine 与 Robot Trajectory，分配对应热源并设置 `Trajectory.index`。同名热源、同名 WeldLine 或已有 Trajectory 的 Robot 会终止执行。

CSV 使用 UTF-8（支持 BOM）和逗号分隔，列名区分大小写。必需列是 `X,Y,Z` 和点序列 `Order`，点序也支持 `Index`、`PointOrder` 或 `PointID`。可选 `PathID` 或 `WeldID` 区分同一文件中的多条路径，可选 `NodeID` 显示原始编号。没有路径编号时文件内全部点属于一条路径。每条路径按点序升序读取。CSV 的其他列不设置网页热源参数、方向或停止时间，这些值以网页输入为准。

```csv
PathID,Order,NodeID,X,Y,Z
Path-A,1,1001,0,0,0
Path-A,2,1002,10,0,0
Path-A,3,1003,20,5,0
Path-B,1,2001,40,0,0
Path-B,2,2002,50,0,0
```

CSV 单位在导入时换算为 mm 保存；模型长度单位用于三维显示换算。两份数据需使用同一坐标系。程序保留全部路径点，连接顺序由点序列确定。每条路径至少包含两个点；点序重复、相邻点重合、非有限坐标和缺少必要列会停止导入并显示原因。一次导入总大小限制 20 MB，当前页面最多导入 1000 条路径、10 万个点；焊接列表最多 1000 条、累计 100 万个点。

INP/BDF 几何背景使用全局坐标下的独立网格。包含 PART、INSTANCE、SYSTEM 的 INP，以及 GRID 使用局部坐标的 BDF，会明确提示转换要求；请由原建模软件输出全局坐标网格后导入。

焊后停止时间对应 `PauseEnd`，`PauseStart`、`LeadTime` 和 `FollowUpTime` 为零。热源使用 `specification.mode="transient-direct"`，设置功率、效率与速度；创建后读取并核对全部参数。脚本同时核对路径点数、长度、热源分配与执行顺序。API 执行中发生异常时会立即终止，Project 中可能保留已经创建的对象。生成完成后使用 Simufact 自身的保存功能保存 Project。

本机没有 Simufact Welding，尚未验证软件内实际创建对象与 PauseEnd 执行效果。

## 从源码运行

需要 Python 3.12 或更新版本、Node.js 22.12 或更新版本。开发环境首次安装需要网络；程序运行不访问外部服务。

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-lock.txt
.venv/Scripts/python.exe -m pip install -e ".[dev]"
npm ci
npm run build
.venv/Scripts/python.exe -m sfmarc_workbench.launcher
```

```powershell
$env:SFMARC_TEST_DAT = "D:/models/model.dat"
$env:SFMARC_TEST_WELD_CSV = "D:/models/nodes.csv"
.venv/Scripts/python.exe -m pytest
```

项目的实际用户模型专项测试仅在对应模型输入下执行。公共测试样本通过固定 commit 下载到被忽略的 `work/`，文件摘要会被核对。

```powershell
.venv/Scripts/python.exe scripts/fetch_sample.py
$env:SFMARC_TEST_DAT = "$PWD/work/elemtype7_tension.dat"
.venv/Scripts/python.exe -m pytest
```

Windows 打包：

```powershell
./scripts/build.ps1 -Python .venv/Scripts/python.exe
```

## 维护与扩展

- `deck.py`：输入文件与 INCLUDE、LOADCASE 位置、原始数据。
- `geometry.py`：表面提取、Marc 面号、法向、积分与角度选择。
- `background.py`：INP/BDF/STEP 第三方读取、表面显示与实体识别。
- `loads.py`：载荷数据、单位换算、合力与导出。
- `welding.py`、`weld_script.py`：CSV 读取、焊路输入检查与 Simufact 脚本生成。
- `server.py`：本机 API、请求来源与会话校验。
- `frontend/viewer.ts`：三维显示、点击与高亮。
- `frontend/main.ts`：共用模型操作、功能入口、参数面板与载荷操作。
- `frontend/welding.ts`：路径选择、焊接顺序、停止时间与脚本导出。
- `frontend/heatSettings.ts`、`weldTimeline.ts`：热源表单、尺寸示意图与按物理时间播放。

功能入口由 `workspaceTools` 定义，`activateTool` 统一切换按钮状态、参数面板和三维标记。功能参数区使用 `data-tool` 与入口 ID 关联；`activate` 恢复该功能的三维标记，`pick` 处理点击表面。模型导入、单位、实体显示和相机控制共用，功能切换保留表单与编辑状态。增加功能时在此列表登记入口并提供对应面板与交互处理。

新增二开功能应复用原始编号和表面数据。新增单元类型需要先核对 Marc 官方连接关系和面号，再使用真实输入验证。源码库不包含用户模型与计算结果。
