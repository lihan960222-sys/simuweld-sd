# SIMUWELD-SD 固有应变法模块重写需求说明

修订日期：2026-11-19

## 1. Eden 源程序与采用范围

计算依据为 Eden 固定端版本（`eden-fixed-end`）中的 `solver.js`、`main.js` 与 `laser.html`。

| 功能 | Eden 源码位置 | 采用的实现 |
| --- | --- | --- |
| 几何与板层 | `solver.js`：`VCLaserGeo.fromModel`、`prep`、`cellFields` | 外轮廓、腔体、上下盖、封边、吸液芯和支撑柱的二维区域表示 |
| 独立网格 | `solver.js:219`：`grid1`、`makeGrid` | 非均匀矩形网格，特征区域加密，间距按比例过渡 |
| 温度计算 | `solver.js:457`：`VCLaserThermal.run` | 上下两层二维薄板导热、LOD 隐式方向分裂、层间换热、焓法相变 |
| 固有应变 | `solver.js:381`：`VCLaserInherent.create` | 两端固定、`r = 1`、单轴理想弹塑性，逐温度步更新状态 |
| 整体变形 | `solver.js:778`：`VCLaserMech.run` | von Kármán 大挠度双层板，BFS 弯曲插值，最终固有应变分步加载 |
| 计算衔接 | `main.js`：`thermal`、`mech`；`laser.html:2738`：`startRun` | 温度计算期间更新应变，保存结果，再启动整体变形求解 |
| 参数与界面 | `laser.html:202–251`、`thermalParams`、`mechParams` | 二维显示、折叠参数、温度到变形的操作流程，以及本说明列出的默认值 |

Eden 的模型入口使用 `vc-model` 或简易几何参数，材料使用内置表，焊路由封边参数生成。DAT、外部材料文件、实际焊路和 Base/Cover 通过本模块增加的输入适配接入这些计算环节。

开发与验收位置：

- SD 源代码：`src/sfmarc_workbench` 与 `frontend`。
- 需求说明：`docs/固有应变法模块重写需求说明.md`。
- 实际输入：`C0002.dat`、`C0003.dat`，由本机测试环境指定。
- Windows 交付入口：`SIMUWELD-SD-Web.exe`。

## 2. 用户操作流程

1. 导入 DAT。程序识别单位，读取几何、板层、焊路、材料引用、时间安排、夹具与换热条件，显示二维外形。
2. 程序自动查找所引用的材料文件，检查计算数据，并生成独立温度网格与结构网格。准备过程显示当前工作、进度与准备耗时。
3. 数据完整时显示“准备完成”，启用“开始计算”。材料依赖缺失时，显示具体文件或材料名称，并提供对应文件选择入口。
4. 用户点击“开始计算”，执行焊接与冷却温度计算，同步更新固定端应变，随后计算整体变形与夹具释放。计算期间可以查看进度与已有结果，也可以停止。
5. 完成后查看温度、固有应变、鼓包与翘曲，导出本次参数和结果。

网格尺寸、计算步长和结束时间均自动填写。参数输入框保留在默认折叠的“高级参数（可选）”中。热源与焊接顺序显示在自动识别的工艺详情中，常规计算无需逐项确认。

## 3. DAT 与材料适配

### 3.1 几何、坐标与板层

- DAT 原有节点和单元用于恢复外轮廓、孔洞、腔体、厚度、上下板关系，以及载荷、接触和约束区域。
- 计算平面依据板件的实际方向确定，几何、焊路、夹具和结果共用同一坐标变换，并保存与 DAT 坐标之间的转换关系。
- 保留实际轮廓、间隙、封边和连接区域。独立网格通过有效区域标记表示板件形状。
- 对应 Eden 的 `outer`、`chamber`、`tT`、`tB`、`tf`、`G0`、吸液芯区域和支撑柱信息建立明确的数据映射。吸液芯与支撑柱按输入中的实际结构建立。
- 温度网格与结构网格分别生成；DAT 单元编号保留作区域追溯。
- 长度、时间、速度、功率、热参数和材料单位统一换算。参照 Eden，界面几何使用 mm，温度求解中的长度换算为 m，结构求解使用 mm、N、MPa。

### 3.2 实际焊路与工艺时间

Eden 的 `VCLaserGeo.weldPath` 根据外轮廓、内缩距离、圈距、圈数和速度生成封边路径。本模块将 DAT 的实际路径接入热源位置随时间变化的接口。

- 保留各段坐标、方向、对应板件、启动时刻、速度、功率、停顿与阶段顺序。
- 多条焊路按文件给定的时间关系执行，路径间隔期间继续计算散热和应变。
- 热源启停、功率变化、接触状态变化和工艺阶段切换均作为时间事件处理。
- 热源输入记录原始功率、效率与最终吸收功率，效率只计算一次。
- DAT 热源转换为二维面热源时，记录厚度方向等效方法与热量分配，核对总输入能量。

### 3.3 材料数据

材料入口需要提供 Eden 计算所需的密度、`k(T)`、`cp(T)`、熔点、潜热、液相热参数、`E(T)`、`alpha(T)`、`sy(T)`、Poisson 比、退火温度与辐射率。

- 优先读取 DAT 的材料定义及其引用文件，保留材料与板层、区域的对应关系。
- 外部材料数据转换为计算使用的材料表；上下盖和吸液芯分别关联实际材料。
- 材料文件已经找到并且有效时，直接进入准备完成状态。
- 缺少必要数据时，就地报告材料名称、缺失项目与文件位置。
- 采用 Eden 材料表时，显示材料名称、初始状态及数据来源。材料表插值和温度范围以外的处理需记录；Eden 的常规表查询采用线性插值及端点值，`alpha(T)` 的积分也需要保持一致。

DAT 和材料格式使用已有读取器与成熟依赖。定宽数值字段使用 `fortranformat` 等对应工具，格式含义依据 Marc 文档及实际输入核查。

### 3.4 热边界与 CONTACT TABLE

| 输入内容 | 适配要求 |
| --- | --- |
| 初始温度、环境温度 | 保留文件中的数值及作用区域 |
| 对流与辐射 | 保留表面、板层、系数和随时间或温度变化的定义 |
| 板间接触换热 | 关联实际接触对、区域、阶段和换热表 |
| 夹具换热 | 由接触区域、夹具温度与换热定义共同确定 |
| CONTACT TABLE | 保留引用编号、独立变量、单位、插值规则与生效阶段 |
| 焊后连接 | 保留焊接形成的连接区域及相应导热状态 |

`C0003.dat` 的 CONTACT TABLE 换热定义必须纳入实际文件验收。逐项核查表格自变量及所需物理量的来源；需要二维等效时，保存原始定义、等效方法与参数依据。

文件提供的热边界优先使用。文件未定义的可选参数使用第 9 节中的默认来源。读取失败时，区分文件缺少定义与读取能力缺失，并显示对象、关键字、表格编号或阶段。

### 3.5 Base/Cover

- 从 DAT 的 CONTACT 刚体几何、点集与接触定义获得 Base、Cover 的位置和作用区域。
- DAT 提供夹具信息时，直接完成映射。
- 夹具的热接触和结构约束分别建立数据，保留接触方向、初始间隙及单向支撑含义。
- 结构计算增加夹紧状态与释放状态两个阶段：夹紧状态使用 DAT 对应约束；释放阶段解除 Cover，保留 Base 单向支撑。

Eden 界面的上下夹具参数用于热交换；其结构求解已有内部支撑柱接触和消除刚体运动的数值约束。Base/Cover 的外部机械接触及释放由本模块补充到结构求解中。

## 4. 独立二维网格

### 4.1 Eden 网格方法

采用 `grid1` 与 `makeGrid` 的非均匀矩形网格方法：

- 分别建立非均匀的 `xs`、`ys` 坐标序列。
- 在特征区间及其两侧 `band` 范围内使用 `hf`。
- 离开加密区域后，网格间距按 `1.3` 的比例逐渐增大，最大间距为 `hc`。
- 温度网格保存有效材料、腔体、厚度、孔隙和层间导热等区域数据。
- 结构网格独立生成，并结合轮廓特征坐标处理边界。

Eden 现有网格特征来自外轮廓与腔壁边线在两个坐标方向的投影。本模块将 DAT 的实际焊路、接触边界和必要的连接区域加入网格特征，保证焊路附近得到加密。

### 4.2 自动填写与网格检查

- Eden 的温度网格默认值为 `hf = 0.2 mm`、`hc = 0.5 mm`、`band = 3 mm`。
- Eden 的结构网格默认值为 `hf = 0.7 mm`、`hc = 3 mm`、`band = 1.5 mm`。
- 自动推荐以这些默认值为依据，结合导入几何的最小连接宽度、热源尺寸、焊路位置与接触区域进行校验和调整。参数框显示实际采用值与调整依据。
- 检查孔洞、狭窄连接、板层覆盖和夹具作用区域；计算区域及焊路必须得到有效网格覆盖。
- 准备完成时显示温度单元数量、结构单元数量、自由度数量及最小间距。
- 用户修改参数并点击“应用参数”后，重新准备受影响的网格。

## 5. 二维温度计算

### 5.1 上下两层温度场

采用 `VCLaserThermal.run` 的上下两层二维薄板模型，每层计算面内温度，厚度参与热容量与导热计算。

- 上盖、下盖分别保存温度；封边与腔体使用对应厚度和层间换热。
- 腔体区域按实际结构计算支撑柱、空气间隙、吸液芯和接触热阻的传热。
- 吸液芯按自身材料及孔隙参数修正有效导热和热容量；其固定端应变更新沿用所在下层温度。
- 计算外表面对流、辐射和夹具换热。
- 使用温度相关的材料参数，通过焓与液相分数处理熔化潜热。

Eden 的高斯表面热源作用于上层，光斑参数是 `1/e²` 直径。热源在单元范围内积分，每个时间步使用四个时间积分点。DAT 适配应保持光斑定义、热源作用板层与吸收功率的单位一致。

Eden 对已熔合区域采用 `H_FUSED = 1e7 W/(m²·K)` 的层间导热系数。DAT 具有明确连接换热定义时按文件处理，采用该模型常量时记录其来源。

### 5.2 LOD 方向分裂

每个时间步遵循 Eden 的计算次序：

1. 按当前温度计算材料与边界系数。
2. 沿 `x` 方向进行隐式三对角求解。
3. 沿 `y` 方向进行隐式三对角求解。
4. 按层间温差衰减的解析关系更新上下层交换热量，保持两层热容量加权的平均温度。
5. 更新焓、液相分数和温度。
6. 接受该时间步后，更新固定端应变与历史统计。

该实现使用逐步更新的非线性系数，每个温度步内部没有 Newton 非线性迭代。出现非有限温度或温度低于允许下界等异常时，恢复该步之前的温度、焓、相态和热输入，减小步长重算。失败的温度步不更新应变历史。

## 6. 自动步长与结束时间

### 6.1 `0.001 s` 的来源

Eden 焊接期间的步长为：

```text
dtW = min(0.001 s, dtFac × hmin / v)
```

其中 `hmin` 与 `v` 使用一致的长度单位，界面调用中的 `dtFac = 1`。默认冷却步长为：停光后前 `0.5 s` 使用 `0.001 s`，随后至 `2 s` 使用 `0.005 s`，以后使用 `0.02 s`。实际步长还受结果保存时刻与异常重算限制。

`0.001 s` 是 Eden 设置的焊接步长上限，其合理性需要结合光斑运动、网格间距与温度变化判断。隐式差分可以减轻稳定性限制，时间精度、温度相关系数与相变处理仍然需要检查；结构部分另有 Newton 收敛要求。

### 6.2 本模块的时间设置

- 程序自动计算并填写最大焊接步长、冷却步长和结果保存间隔，保留高级参数输入框。
- 以 Eden 的计算规则作为默认依据，显示限制来源和本次实际最小、最大步长。放宽步长需要通过真实小模型的短程步长减半对照检查温度和固有应变变化。
- 步长准确到达热源启停、路径切换、边界变化与结果保存事件。
- 结果保存间隔与计算步长分别管理。每个接受的计算步都更新应变，结果显示可以降低保存频率。
- Eden 的焊接帧间隔为 `max(0.01 s, ceil(tOff / 160 / 0.005 s) × 0.005 s)`；DAT 多阶段流程沿用独立保存间隔的处理方式，并补充阶段边界帧。
- 记录步长缩减次数、最小步长、实际热输入及异常位置；重算仍失败时，立即报告原因。

### 6.3 工艺结束与冷却

Eden 使用 `tOff = path.tEnd`、`tEnd = tOff + tCool`，界面默认 `tCool = 6.5 s`。

- DAT 明确给出的焊接、停顿、保温和冷却阶段全部保留，程序自动计算工艺结束时刻。
- 文件没有给出附加冷却时间时，自动填写 Eden 的 `6.5 s` 默认值，并在高级参数中标明来源。
- 工艺结束时刻、附加冷却时间、最终计算截止时刻分别显示。用户无需填写结束时间。
- 所有加热、重复加热、间隔、保温与冷却温度步持续更新应变状态。
- 记录截止时的最高温度、最低温度与液相数量。截止时仍有液相的任务自动继续冷却到全部凝固，随后检查结构求解条件。
- 按 Eden 保存 `strainState`：所有有效材料温度与初始参考温度 `T0` 的差值均不超过 `0.5 ℃` 时，标记 `reference-temperature`；其余标记 `end-of-calculation`。
- `0.5 ℃` 用于应变结果的温度状态分类。`6.5 s` 用于缺少定义时的默认附加冷却时长。界面根据实际温度显示截止状态。

## 7. 固定端固有应变

### 7.1 局部模型与公式

采用 `VCLaserInherent.create` 的两端固定单轴理想弹塑性模型，总应变为零，`r = 1`。

```text
eth(T) = integral(alpha(theta), theta = T0 ... T)
sigmaTrial = -E(T) × (eth(T) + ref + ep)
deltaP = max(abs(sigmaTrial) - sy(T), 0) / E(T)
ep = ep + sign(sigmaTrial) × deltaP
epsStar = ep + ref
```

- 每个有效温度单元分别保存 `ep`、`ref`、`annealed`、`liquid`。
- `ep` 为带符号的塑性应变，`ref` 为熔化及凝固处理中采用的参考应变。
- `alpha(T)` 按温度积分；采用分段线性材料表时，对每个区间进行对应积分。
- `E(T)` 与 `sy(T)` 随温度更新，拉伸与压缩屈服均参与计算，冷却期间保留反向屈服。
- 每个接受的温度步均调用状态更新。初始状态也参与初始化处理。
- 温度历史逐步推进状态，内存中的核心状态规模随网格数量增长。

### 7.2 退火、熔化与凝固

- 达到退火温度后，永久记录 `annealed = 1`，后续采用退火态 `sy.O`。
- 液相按零承载处理：`ep = 0`，`ref = -eth(Tm)`，应力为零。
- 从液相转回固相时，保留在熔点建立的无应力参考，再按后续冷却过程更新塑性。
- 重复熔化与重复热循环继续按实际状态推进。
- 材料初始状态、退火温度、参考温度和相态随结果保存。该模型的凝固参考处理按上述公式执行。

### 7.3 应变输出与结构使用

- 输出上盖 `epsT`、下盖 `epsB`、吸液芯 `epsW`，其数值定义均为 `ep + ref`。
- 保留带符号应变。完整热历史累计过程中，不设置人为应变截断值；反向屈服可以改变已有塑性应变。
- 上盖与下盖使用各自温度历史，吸液芯使用下层温度与自身材料。
- 结构加载沿用 Eden 的等向面内赋值：`eps_x = eps_y = epsStar`、`gamma_xy = 0`。
- 导出明确记录“固定端单轴局部模型、面内等向应变加载”的模型定义，并保存截止温度状态。
- `r = 1` 是局部应变计算假设；DAT 外部夹具作用于整体结构求解。

## 8. 整体变形与夹具释放

### 8.1 应变传递与板模型

采用 `VCLaserMech.run` 的独立结构网格与双层板表示。

- 温度网格到结构网格按有效材料交叠面积加权传递 `epsT`、`epsB`、`epsW`。
- 检查板层与坐标一致性，检查有效结构区域的应变覆盖。缺失覆盖时在对应区域报告错误。
- 板的面内位移使用双线性插值，弯曲使用 BFS（Bogner–Fox–Schmit）双三次 Hermite 插值。
- 每个节点有六个自由度：`u`、`v`、`w`、`w_x`、`w_y`、`w_xy`。
- 使用 Kirchhoff–Love 薄板与 von Kármán 大挠度关系，计算膜应变与弯曲。
- 分层厚度积分得到 `A`、`B`、`D`，并由各层固有应变生成膜内力和弯矩。
- 结构弹性模量沿用 Eden 的 `MS.E[0][1]`、`MW.E[0][1]`，采用材料弹性表首个温度点的数值。材料适配时核查该温度点的含义；局部固定端应变更新使用各温度步的 `E(T)`。
- 下盖覆盖完整板件；封边区组合下盖和上盖封边，腔体区组合下盖与实际吸液芯。腔体上盖单独建立板层。
- 腔体边缘沿用 Eden 的侧壁刚性连接关系，保留上下参考面的高度差。
- 内部支撑柱采用单向接触，阻止上下盖相互穿透。

### 8.2 加载与平衡

1. 完成全部规定温度历史，检查应变数据、材料状态与液相数量。
2. 生成独立结构网格并传递最终固有应变。
3. 在 Base/Cover 对应约束下，将最终固有应变按载荷比例逐步施加，求解夹紧状态的整体平衡。
4. 解除 Cover，保留 Base 单向支撑，求解释放后的平衡与形状。

Eden 的结构载荷步是最终固有应变的加载比例，温度历史与结构加载各自记录时间或步数。整体结构在热历史完成后求解。

- 默认采用 Eden 的 Newton 迭代、带状 LDLT 分解与能量回溯线搜索；切线矩阵需要时采用对角移位。
- 参照界面调用，默认加载 `12` 步，每步最多 `25` 次 Newton 迭代，相对残差容限为 `3e-4`。
- 每个加载与释放阶段记录载荷比例、迭代次数、接触数量、残差与终止原因。
- 完成判定同时检查全部载荷是否施加、接触是否满足要求及最终平衡残差。
- 位移增量很小而残差仍超限时，显示未收敛状态并保留诊断数据。
- DAT 外部约束与消除刚体运动的数值条件分别记录，数值条件应保留板件可发生的物理变形。

### 8.3 初始形状与结果定义

- Eden 默认上盖半波初始外凸幅值为 `10 µm`，下盖采用反向一半幅值，即 `-5 µm`。
- DAT 具有实际初始形状时，使用其几何信息；使用默认初始外凸时，在高级参数和导出中记录。
- 比较工艺时保持初始形状设置一致。
- 保留原始位移 `wB`、`wT`。参照 Eden，以拟合下盖参考平面扣除刚体倾斜，得到 `zB`、`zT`。
- 下盖翘曲 `warpPV = max(zB) - min(zB)`；顶面起伏 `topPV = max(zT) - min(zT)`。
- 上下盖附加开口 `gap = wT - wB`；鼓包指标 `bulgeMax = max(0, max(gap))`，同时记录位置。

## 9. 参数默认值与来源

高级参数保留输入框，按当前模型自动填入数值、单位、作用范围和来源。以下 Eden 数值作为缺少定义时的默认依据；DAT 和实际材料中的对应定义优先使用。

| 参数 | Eden 的实际默认值或规则 | 本模块填写要求 |
| --- | --- | --- |

| 网格过渡 | 间距增长比例 `1.3` | 显示实际采用的过渡规则 |
| 结构网格 | `hf = 0.7 mm`、`hc = 3 mm`、`band = 1.5 mm` | 检查板层、接触区与应变覆盖 |
| 焊接步长 | `min(0.001 s, hmin / v)` | 自动计算，显示上限与实际使用范围 |
| 冷却步长 | `0.001 / 0.005 / 0.02 s` 分段 | 按时间事件截取，异常时减小步长 |
| 附加冷却 | `6.5 s` | 文件缺少定义时自动填写，并记录最终温度状态 |

## 10. 界面、进度与停止

### 10.1 二维显示

- DAT 导入后直接显示板件的二维平面外形，方向与温度计算平面一致。
- 温度区域采用固定二维正交显示，提供缩放、平移、适应窗口和板层切换。
- 外轮廓、独立网格、焊路与夹具区域可以分别控制显示。
- 温度结果提供时间选择、播放、跟随最新结果、图例范围与历史最高温度。
- 固有应变提供上盖、下盖和实际吸液芯的二维分布。
- 结构结果提供变形图、截面及鼓包、翘曲数值；变形倍率明确显示。

### 10.2 状态与按钮

| 状态 | 用户可以看到与执行的操作 |
| --- | --- |
| 等待导入 | 导入 DAT |
| 正在准备 | 当前读取或网格工作、准备进度、准备耗时、停止 |
| 输入待补充 | 缺少的材料或必要数据，以及对应处理入口 |
| 准备完成 | 自动识别信息、网格数量、可用的“开始计算” |
| 焊接与冷却计算 | 当前工艺阶段、模拟时刻、阶段进度、计算耗时、已有温度结果、停止 |
| 结构加载或夹具释放 | 载荷比例、迭代次数、平衡残差、接触状态、计算耗时、停止 |
| 正在停止 | 当前终止位置与状态，防止重复提交 |
| 已停止 | 实际截止阶段、有效结果、导出与重新开始 |
| 任务失败 | 错误对象、位置、原因和日志 |
| 计算完成 | 结果、温度截止状态、结构收敛状态与导出 |

- 准备计时和计算计时分别记录。“开始计算”实际启动求解后，计算计时才开始。
- 开始按钮不可用时，按钮旁持续显示原因，例如“正在生成温度网格”或“缺少材料文件”。
- 导入后自动准备；修改参数需要再次准备时，显示对应操作与状态。
- 温度阶段按真实模拟时间或已完成阶段显示进度；结构阶段按载荷步与迭代显示进度。
- 总量未知时显示当前工作与耗时；阶段进度不能仅由墙钟时间推算。

### 10.3 后台执行与停止

Eden 通过 Worker 的 `thermal` 与 `mech` 命令依次执行计算，已有进度回调；本模块补充准备、温度、冷却、结构与释放阶段的停止处理。

- 计算在后台 Worker 或后台进程执行，主界面保持可以操作。
- 热过程在计算步边界、结构过程在迭代边界检查停止请求。准备过程也设置可终止的工作边界。
- Worker 内同步长循环需要使用能够在执行期间生效的取消机制；实现时验证真实后台工作已经终止。
- 定期保存已接受的温度步状态、结果帧和已收敛的结构阶段。停止后保留这些有效结果，并显示截止位置。
- 未完成的结构迭代数据用于诊断，结果界面明确显示其状态。
- 每次导入、准备和计算具有对应任务编号与模型版本。旧任务返回值仅能更新其所属记录。
- 重新开始使用完整初始状态；模块切换保持各模块自己的材料、参数、状态和结果。

### 10.4 导出

导出包含输入与材料校验信息、单位、坐标变换、实际工艺、热边界、夹具、参数及来源、两套网格、已保存温度帧、最高温度、`epsT`、`epsB`、`epsW`、原始位移与参考平面处理后的结果、鼓包和翘曲指标、各结构阶段残差、夹具释放状态、实际截止时刻及 `strainState`。

## 11. 验证与验收

### 11.1 计算核心的小范围验证

使用真实计算函数、真实小模型和有解析关系的材料参数，完成必要的算法检查：

- 温度：两层传热、热输入与能量关系、相变、实际事件时间、短程步长减半对照。
- 固定端：屈服前弹性、带符号塑性更新、冷却反向屈服、退火、熔化后无应力参考、重复热循环。
- 历史：每个接受步均更新应变；温度步重算与显示帧间隔不会重复或遗漏应变更新。
- 传递与结构：面积加权传递、双层板关系、初始形状、固有应变加载、单向支撑、Cover 释放与最终残差。
- 衔接：小模型完成温度、应变、结构与释放的完整调用，输出数值有限且状态一致。
- 停止：真实终止后台工作，停止后保留有效结果，重新导入后旧任务无法改变当前状态。

可复用 Eden 的 `test_inherent.cjs`、`test_thermal.cjs` 与 Worker 检查中的有效工况，按实际适配补充必要检查。

### 11.2 实际 DAT 的读取与准备

- 使用 C0002、C0003 验证几何、板层、材料引用、焊路、时间、Base/Cover 与换热定义。
- 对照文件核查代表性区域、接触对、表格与时间阶段。
- C0003 必须完成 CONTACT TABLE 换热定义的读取及准备验证。
- 检查独立网格、参数自动填写、二维显示数据与夹具映射。
- 实际文件验证限于读取、准备与必要的短程检查。完整工况由用户通过交付界面提交计算。
