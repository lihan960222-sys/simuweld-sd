# 局部试算实施计划

**目标：** 在当前 SD 中选择代表性焊路、截取完整单元、设置节点约束并导出 Simufact 局部试算文件组。

**结构：** 复用现有 DAT 读取器和三维视窗；local_trial.py 处理连续路径、历史匹配与截取；独立模板通过已确认 Simufact API 创建 Process。前端单独模块保存试算组，服务端从原模型重新校验导出。

**使用技术：** Python、NumPy、SciPy、第三方网格读写库、FastAPI、TypeScript、Three.js。

**依据：** 本次对话用户确认 Q1–Q23 及最终选择。保留当前工作目录和已有变更。

## 要求

- 生成焊路排在面载荷之前；新增局部试算模块。
- 原始文件只读；不自动上传 GitHub，不删除历史交付。
- 路径按连续几何匹配，默认距离 0.01 mm；不同点密度与方向均保留原时序。
- 包围盒保留相交完整单元；Base 完整保留；其他无关焊路不参与。
- 多组独立算例；每组包含同区域历次焊接及原等待时间。
- 支持端点/中心长度、闭合路径、去头尾双端滑条、节点/面/框选/反选及 XYZ 约束。
- 生成局部网格、manifest、创建脚本。Simufact 负责生成求解 DAT。
- 开启应变张量输出；最高板件温度 26 ℃、冷却超时明确失败。
- 未确认的原项目边界重建能力必须报告，不能生成看似成功的错误模型。

## 验证重点

- 不同采样密度、反向路径、闭合跨接缝、部分覆盖、相交不同路径。
- 单元没有节点在盒内但与盒相交；Base 不截取；裁剪后面号/节点映射。
- 模型更换后的旧请求和旧选区；非法节点和无效约束方向。
- 多次焊接之间的真实等待时间与历史状态；局部路径热源继承。
- 本机无 Simufact 运行环境时明确区分接口及数据验证和目标环境执行验证。
