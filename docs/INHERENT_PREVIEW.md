# 固有应变法

## 操作

1. 进入“固有应变法”，导入 Marc DAT，确认模型长度单位。程序自动恢复板件轮廓、孔洞和厚度，生成独立计算网格。准备区域显示阶段、进度、准备耗时和停止按钮。
2. 在「温度」中选择 XMT 材料，点击「计算温度」。完成后可切换当前温度帧和历史最高温度。程序为应变求解暂存每个接受热步的温度。
3. 打开「固有应变」，点击「计算固有应变」，沿已算出的温度历程累计塑性应变。选择 XX、YY 或等效塑性应变查看分布。
4. 打开「位移」，点击「计算位移」。结构求解使用上一阶段的应变和 DAT 的夹具条件，完成后可调整变形显示倍率。「色标与导出」可设置图例和保存已完成的结果。

「网格与换热参数」默认收起，输入框自动填入默认值，旁边显示来源。修改后点击“应用参数”。网格参数变化会自动重新准备；其他参数用于下次计算。点击“恢复默认值”后继续点击“应用参数”。

## 二维显示

温度视图使用固定二维正交相机，每次显示一个板层。可以选择板层，控制独立计算网格、焊路和夹具区域的显示。鼠标滚轮缩放，鼠标右键平移，顶部按钮适应窗口。图例上下限可以修改，温度帧可以拖动，计算期间可以跟随最新帧。

DAT 原有单元用于恢复几何与物理条件的作用区域。温度网格和 Shell 网格由程序独立生成。结构位移显示支持三维旋转，选择温度后恢复二维视图。

## 默认参数

| 参数 | 默认来源 |
| --- | --- |
| 焊路附近网格尺寸 | 最小热源半径的 1/4 |
| 远离焊路的网格尺寸 | 焊路附近尺寸的 4 倍 |
| 加密距离 | 最大热源截断半径加上两倍焊路附近尺寸 |
| 最大时间步长 | 根据热源半径、最小网格间距与移动速度计算，并限制在 0.1 s 以内 |
| 工艺结束时刻 | DAT 各阶段持续时间累计 |
| 结果保存间隔 | 工艺结束时刻的 1/200，至少 0.000001 s |
| 初始温度 | DAT INITIAL TEMP；未定义时使用 25 ℃ |
| 表面对流、辐射、环境温度 | DAT CONTACT 的板件热条件 |
| 板间和夹具换热 | DAT CONTACT TABLE 与刚体温度 |

默认参数按板层和接触对分别应用；高级参数中的数值显示首个对应区域的代表值。手动修改某项参数后，该项数值统一应用到全部对应区域。缺少 CONTACT 环境定义时使用 25 ℃、10 W/(m²·K) 对流和 0.2 辐射率；缺少工件接触或夹具换热定义时对应系数取零。焊后连接换热的程序推荐值为 10000 W/(m²·K)，夹具温度默认值为 25 ℃，各项来源在参数旁说明。

工艺详情显示 DAT 热源、功率、路径、焊接顺序、阶段时间、夹具与热边界来源。程序支持 CONTACT 2 的显式 type 7 patches/points，以及阶段条件恒定的 CONTACT TABLE 2。随阶段变化的接触条件、近接触换热、近接触辐射、表格边界和其他未支持的定义会报告具体原因。

Simufact 的特殊负值接触定义当前使用等效换热系数 1000 W/(m²·K)，工艺详情和导出参数中明确标记。C0002 包含一项此类定义。该数值属于模型假设，正式精度评价需要确认对应的接触物理意义。

## 时间积分与计算过程

空间采用平面差分，时间采用隐式积分。温度相关材料、焓和辐射需要非线性迭代。步长同时影响热源运动分辨能力、时间精度与迭代过程；程序根据热源尺寸、移动速度和温度变化自动调整，准确到达工艺事件与结束时刻。高级参数中的最大时间步长为上限。

1. 每个板层采用厚度平均温度，计算面内导热、板间换热、夹具换热、外表面对流和辐射。材料热物性与潜热取自 XMT。
2. 每个温度步更新完全约束平面应力 J2 塑性历史，使用温度相关弹性、热膨胀、屈服和硬化。加热、冷却、重复加热均参与累计。
3. 完成 DAT 全部工艺后继续冷却，直到各板层与对应环境温度的最大温差不超过 5 ℃。冷却时间超过 3600 s 会报告错误。
4. 按交叠面积把最终塑性应变传递到独立的 MITC4 Shell 网格，保留四个面内积分点和五个厚度积分点，计算全部固有应变作用下的整体平衡。
5. 解除 Cover，保留 Base 单向支撑，计算释放后的位移。提前结束工艺时保持 Cover，并在界面和导出中标记。

Base、Cover 位置来自 DAT 刚体几何。材料温度表超过上限时采用端点延拓，保留实际温度供检查；当前计算包含夹具与板件之间的等效换热，未求解刚体内部温度场和蒸发。Shell 使用小应变与适度转角假设。

## 导出

ZIP 保存模型与材料校验值、默认参数、参数来源、实际设置、热边界、温度网格、温度帧和历史最高温度。结构计算完成后还包含：

- `mechanics.json`：界面位移与应变数据。
- `mechanics.npz`：结构网格、节点位移与转角、积分点塑性历史，剪切分量使用 Mandel 记法。
- `equilibrium.json`：整体加载、夹具释放和平衡残差。

## 验证

4×2 mm 双层小模型使用真实 C19000 材料与 DAT CONTACT，80 个温度单元、16 个 Shell 单元和 500 W 锥形热源，完成加热、塑性累计、冷却、整体平衡、Cover 释放与导出一致性检查。峰值温度 228.849 ℃，最终温度 28.855 ℃，最大塑性应变 0.000851936，最大位移 0.001296749 mm，最终平衡残差 3.4904×10⁻¹¹ N。

浏览器操作检查覆盖自动准备、可选参数修改与恢复、独立计时、二维相机、板层选择、显示开关、真实小模型计算、停止、结果查看、导出和重新导入。C0002 仅检查 DAT 读取和热边界识别。

Eden 参考文件为固定端版本的 `solver.js`。本模块参考其中的二维温度、独立网格、焊接与冷却时间处理，沿用 SD 已有的温度相关材料、塑性历史和 Shell 整体平衡实现。
